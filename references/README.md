# Справочные источники

Первичный источник для разработки — предоставленный файл Atlas_DnD_Warcraft_Reference.json. Находите разделы через toc, берите правила из pages и указывайте printed_page. Идентификаторы — phb2024, dmg2024, wow. В репозитории и в клиентской сборке публикуются производные справочники и точечные ссылки на страницы. Справочный корпус хранится отдельно.
