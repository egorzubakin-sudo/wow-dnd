# Пакеты контента

- [core](core/README.md) — базовые справочники и книжные записи.
- [professions](professions/README.md) — рецепты, ингредиенты и производственные цепочки.
- [gathering](gathering/README.md) — добыча и таблицы ресурсов.
- [regions](regions/README.md) — региональные пакеты, рынки, услуги и NPC.
- [adventures](adventures/README.md) — задания, решения и последствия.
- [campaign](campaign/README.md) — настройки конкретной кампании.
- [examples](examples/README.md) — учебные пакеты для отдельной установки.

Движок читает пакет при подтверждении импорта в Мастерской. Формат описан в [CONTENT_GUIDE.md](../CONTENT_GUIDE.md).
