Warcraft: Век Авантюристов

Локальное приложение для кампании между сессиями D&D.

Скачать полную сборку · ZIP Открыть Атлас в новой вкладке Открыть онлайн-кампанию

Кнопка открытия работает из распакованной папки. Оставьте рядом с index.html папку assets/ и файл icons.json.

Быстрый запуск после распаковки

  • Windows — запустите start-atlas.bat.
  • macOS — запустите start-atlas.command.
  • Универсальный запуск — выполните python3 start-atlas.py из папки сборки.

Для скриптов нужен Python 3. Скрипт открывает приложение в браузере по адресу http://localhost:8000/. Оставьте окно запуска открытым на время работы.

Можно открыть index.html двойным щелчком, если браузер разрешает доступ к локальным файлам. Для прежних сохранений используйте тот же браузер и адрес, что и раньше. При смене адреса перенесите кампанию через экспорт и импорт JSON.
