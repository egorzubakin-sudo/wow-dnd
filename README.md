# Атлас расколотого мира · 1.0 RC1

Локальный Атлас для кампании Warcraft между сессиями D&D. Откройте **index.html** из распакованной сборки. Стили, JavaScript, справочник правил и демонстрационный пакет встроены в страницу. Для иллюстраций и выбора иконок оставьте папку `assets/` и файл `icons.json` рядом с `index.html`.

## Скачать и открыть

**[Скачать полную сборку ZIP](https://github.com/egorzubakin-sudo/wow-dnd/archive/refs/heads/main.zip)** · [Страница запуска](start.html)

1. Распакуйте архив. Откройте `start.html` или запустите `start-atlas.bat` на Windows, `start-atlas.command` на macOS либо `python3 start-atlas.py` из папки сборки. Скрипт откроет Атлас в отдельной вкладке на `http://localhost:8000/`. Для последующих запусков используйте тот же браузер и адрес. Если уже пользуетесь Атласом по другому адресу, сохраните этот адрес или перенесите кампанию через экспорт и импорт JSON.
2. Создайте первый аккаунт мастера. Откройте значок профиля в шапке для управления пользователями. Игроку можно назначить несколько героев. Локальный вход рассчитан на доверенное устройство.
3. Для знакомства с новой кампанией загрузите демонстрационные узлы на карте. Отдельно в «Мастерской» выберите «Добавить демонстрационный набор». Для действующей кампании можно загрузить собственные справочники через мастерскую.
4. Выберите героя и откройте «Профиль героя». Например, для добычи меди назначьте «Инструменты каменщика», для выплавки добавьте известный рецепт `make-bar`. Разбейте стоянку в Дуротаре, укажите узел карты и местную услугу «Оружейная» либо откройте это улучшение лагеря.
5. На «Стоянке» откройте карточку горного дела. Через «Сумки» можно передать руду другому герою. В «Ремесле» выберите рецепт и сверяйте расходы перед изготовлением. Если времени на всю партию не хватает, материалы резервируются, а работа продолжается во вкладке «Проекты». Мастер завершает стоянку через окно управления.

Сборку также можно открыть напрямую в браузерах с Web Crypto, IndexedDB и Web Locks на `file://`. Если браузер блокирует чтение реестра, откройте `icons.json` вручную в окне библиотеки. Локальный HTTP работает без доступа в интернет.

Мастер может выбрать иконку любого раздела через «Настройки Атласа» → «Иконки меню». У предметов, профессий, заданий, фракций, персонажей, достижений и улучшений лагеря библиотека открывается из карточки или меню действий. Поиск работает по имени файла. Загруженная вручную иконка отображается поверх выбора из библиотеки.

## Перенос из v0.9

В старом Атласе выполните «Экспорт JSON» в режиме мастера. Сохраните исходный JSON отдельно. Запустите новую сборку и войдите мастером. Если адрес браузера совпадает, при первом запуске приложение проверит базу v0.9 и её резерв в localStorage. При другом адресе или профиле используйте кнопку «Импорт» в шапке и подтвердите замену кампании. Проверьте героев, изображения, казну и начатый маршрут. Проведите контрольный экспорт.

Аккаунты привязаны к этому браузеру и адресу. Для переноса на другое устройство экспортируйте кампанию, создайте там аккаунты и назначьте героев по ID. Мастерская принимает таблицы справочников. Полный JSON кампании импортируется через шапку.

## Справочники и разработка

[Короткая инструкция по заполнению полей импорта](IMPORT.md).

Версионные пакеты, учебный торговый цикл и выборочную книжную экипировку можно загрузить через «Мастерская → Пакеты контента». [Руководство по пакетам](CONTENT_GUIDE.md)

- `SPECIFICATION.md` содержит генеральное ТЗ. Архитектура, правила и ход приёмки описаны в `ARCHITECTURE.md`, `RULES.md`, `ROADMAP.md` и `CHANGELOG.md`.
- `data/rules.json` содержит производный справочник с идентификаторами книг и печатными страницами. `data/demo.json` — пример связанного пакета для мастерской. Книжный рецепт зелья подводного дыхания отмечен отдельно от тестовых рецептов.
- `data/templates/` содержит пустые и заполненные CSV и JSON для 33 справочников. `data/schema.json` описывает поля, типы и внешние ключи. Пример отдельной строки может ссылаться на записи другого справочника. Для первоначальной загрузки связанных таблиц используйте один пакет JSON.
- `legacy/atlas-v09.html` — исходный снимок. `src/atlas-shell.html` — развиваемая оболочка. Модули в `src/` содержат игровые команды и их интерфейс.
- Сборка из корня репозитория: `python3 scripts/build.py`. Обновление реестра иконок: `python3 scripts/icons.py`. Обновление шаблонов: `node scripts/templates.cjs`. Проверки: `node tests/core.cjs` и `python3 tests/browser.py`. Браузерные тесты используют Python Playwright, установленный Chromium в /usr/bin/chromium, временный профиль и свободный порт.

## Личный кабинет и спутники

После входа игрок открывает «Мой герой». Для списка участников, хартии, грамот и коллективных достижений используйте «Компания».

Мастер назначает роли через «Компания → Управление компанией → Назначить NPC» или через меню существующего досье. Роли спутника и специалиста можно совмещать. В редакторе взаимодействия выберите связанную активность, запись и условия. Если действие требует решения за столом, игрок может оставить обращение. Мастер разбирает его в Мастерской. Дополнительные расходы списываются при выполнении связанного действия или при принятии обращения.
