# Атлас расколотого мира · 1.0 RC1

Локальный Атлас для кампании Warcraft между сессиями D&D. Рабочая сборка — **index.html**. В неё встроены стили, JavaScript, справочник правил и демонстрационный пакет.

## Первый запуск

1. Распакуйте архив в отдельную папку. Из этой папки выполните `python3 -m http.server 8000 --bind 127.0.0.1` и откройте `http://localhost:8000/index.html`. Для последующих запусков используйте тот же браузер, адрес и порт.
2. Создайте первый аккаунт мастера. Нажмите своё имя в шапке для управления пользователями. Игроку можно назначить несколько героев. Локальный вход рассчитан на доверенное устройство.
3. Для знакомства с новой кампанией загрузите демонстрационные узлы на карте. Отдельно в «Хранилище» выберите «Добавить демонстрационный набор». Для действующей кампании можно загрузить собственные справочники через мастерскую.
4. Выберите героя и откройте «Профиль героя». Например, для добычи меди назначьте «Инструменты каменщика», для выплавки добавьте известный рецепт `make-bar`. Разбейте стоянку в Дуротаре, укажите узел карты и местную услугу «Оружейная» либо откройте это улучшение лагеря.
5. Через «Добыча» потратьте время на горное дело. Через «Сумки» передайте руду другому герою. В «Книге рецептов» зарезервируйте материалы, затем внесите часы работы. Мастер закрывает стоянку после завершения запланированных действий.

Один файл HTML также предназначен для прямого открытия в браузерах с Web Crypto, IndexedDB и Web Locks на file://. Проверенный в облачной среде способ — локальный HTTP. Интернет для этого способа не требуется.

## Перенос из v0.9

В старом Атласе выполните «Экспорт JSON» в режиме мастера. Сохраните исходный JSON отдельно. Запустите новую сборку и войдите мастером. Если адрес браузера совпадает, при первом запуске приложение проверит базу v0.9 и её резерв в localStorage. При другом адресе или профиле используйте кнопку «Импорт» в шапке и подтвердите замену кампании. Проверьте героев, изображения, казну и начатый маршрут. Проведите контрольный экспорт.

Аккаунты привязаны к этому браузеру и адресу. Для переноса на другое устройство экспортируйте кампанию, создайте там аккаунты и назначьте героев по ID. Мастерская принимает таблицы справочников. Полный JSON кампании импортируется через шапку.

## Справочники и разработка

- `SPECIFICATION.md` содержит генеральное ТЗ. Архитектура, правила и ход приёмки описаны в `ARCHITECTURE.md`, `RULES.md`, `ROADMAP.md` и `CHANGELOG.md`.
- `data/rules.json` содержит производный справочник с идентификаторами книг и печатными страницами. `data/demo.json` — пример связанного пакета для мастерской. Книжный рецепт зелья подводного дыхания отмечен отдельно от тестовых рецептов.
- `data/templates/` содержит пустые и заполненные CSV и JSON для 19 таблиц. `data/schema.json` описывает поля, типы и внешние ключи. Пример отдельной строки может ссылаться на записи другого справочника. Для первоначальной загрузки связанных таблиц используйте один пакет JSON.
- `legacy/atlas-v09.html` — исходный снимок. `src/atlas-shell.html` — развиваемая оболочка. Модули в `src/` содержат игровые команды и их интерфейс.
- Сборка из корня репозитория: `python3 scripts/build.py`. Обновление шаблонов: `node scripts/templates.cjs`. Проверки: `node tests/core.cjs` и `python3 tests/browser.py`. Браузерные тесты используют Python Playwright, установленный Chromium в /usr/bin/chromium, временный профиль и свободный порт.
